# 指间 · 打字练习室（Keystroke · Typing Studio）

一个纯前端、可离线运行的英文打字练习应用：一边练指法，一边记单词，也能练完整句子或自己导入的文本。

界面默认中文，可在设置中切换为英文；练习内容始终保持英文原文，不做翻译。

## 快速开始

1. 下载或克隆本目录；
2. 直接双击 `index.html`，用浏览器打开即可。

没有安装步骤、没有构建流程、没有第三方依赖，也不需要联网。所有脚本通过相对路径加载，`file://` 协议下可正常运行。

如果希望局域网内其他设备访问，也可以用任意静态服务器打开本目录，例如：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。上传到 GitHub 后，同样可以直接用 GitHub Pages 托管。

## 主要功能

### 练习与课程

- **首页推荐**：打开应用后，首页主卡自动推荐「常用单词」词库里下一关未完成的关卡，点一下即可开练。
- **课程库**：包含三门内置课程
  - 基础指法（12 关，按顺序解锁，覆盖基准键、上下排、标点、数字行、Shift 与综合练习）；
  - 常用单词（8 组高频/主题词汇，每个单词附中文释义）；
  - 句子练习（短句与长句，附中文翻译）。
- **逐字符反馈**：正确/错误即时高亮，虚拟键盘同步提示下一个键与本次易错键，可在设置中关闭键盘提示。
- **实时指标**：速度（WPM）、正确率、用时、连击、进度实时更新。
- **结果页**：练习结束后给出星级、速度、准确率、错词回顾与热键提示；成绩达到 3 星需准确率 ≥ 98% 且速度达到该关目标值，准确率 ≥ 92% 为 2 星，其余为 1 星。

### 导入内容与自动解析

在「课程库」页点击「导入内容」，可以：

- 直接粘贴文本，或选择 `.txt` / `.csv` / `.tsv` 文件（单个文件不超过 2 MB）；
- 选择解析方式：自动、纯文本、表格（CSV）；
- 应用会自动完成解析：
  - 按换行与句末标点切分内容；
  - 只含一个英文单词的片段识别为单词，其余识别为句子；
  - 表格模式下默认第一列是内容、第二列是释义，并自动跳过 `word/meaning` 之类的表头；
  - 统一转为小写、清理多余标点与空白、自动去重；
  - 单词每 20 个一组、句子每 6 句一组生成关卡（最多保留 400 个单词、200 个句子）；
- 导入前可实时预览识别结果与将生成的关卡数量；
- 确认后，导入内容会作为独立课程出现在「课程库」，可以像内置课程一样点进真实练习；导入记录保存在本地，可随时在课程库中删除。

### 自定义练习

在「课程库」页点击「自定义练习」，粘贴任意英文文本即可开始一次临时练习（同样走自动解析，不写入课程库）；当首页没有待练习的推荐关卡时，主卡片也会给出该入口。

### 语音朗读

- 使用浏览器/系统自带的语音合成，优先挑选自然音色（如系统内的 neural / natural / enhanced 或常见高质量音色）；
- 支持美式、英式与自动三种口音偏好，可在设置中指定具体音色并调整语速（0.7×–1.15×）；
- 练习中可播放当前单词/句子、重复当前句；读完自动停在当前句，不会自动连播下一句；
- 可开启「自动朗读」，每进入一个新词/新句时自动发音；
- 完全离线；若系统没有可用的在线音色，会自动回退到本机音色。

### 统计与错词本

- **首页**：今日练习时长、今日速度、总正确率、连续天数、最近练习记录、速度趋势与成就概览。
- **数据统计**：累计练习次数、累计字符、最佳速度、总准确率、完成关卡数、累计时长；速度趋势图、键盘热力图、日历热力图、全部成就与最近 12 次练习记录。
- **错词本**：自动收集练习中打错的内容（含中文释义、错误次数、最近出错时间），可单项移除、清空，或一键生成「错词复习」练习。

### 成就与成长

- 完成练习获得 XP，每 300 XP 升一级，侧栏显示等级、进度条与连续练习天数；
- 内置 12 个成就（首练、30/50/70 WPM、100% 准确率、连续 3/7 天、完成 5/15 关、通关基础指法、累计字符、完成错词复习），达成时即时提示。

### 界面

- **中英界面切换**：设置 → 外观 → 界面语言，即时切换并保存到本地，刷新后保持。
- **深浅色**：浅色、深色、跟随系统三种模式，首屏即按保存的偏好着色，避免闪白。

## 目录结构

```
outputs/
├── index.html            应用入口与页面骨架（含 SVG 图标符号）
├── README.md
└── assets/
    ├── styles.css        全部样式（含深色主题与响应式断点）
    ├── i18n.js           多语言核心：注册语言包、取词、插值、应用 DOM 文案
    ├── lang/
    │   ├── zh.js         中文界面文案
    │   └── en.js         英文界面文案
    ├── data.js           内置课程、关卡、成就数据；按当前语言生成视图数据
    ├── store.js          本地数据层：练习记录、进度、错词、成就、设置（localStorage）
    ├── speech.js         语音朗读：音色优选、口音、语速、播放状态
    ├── practice.js       练习引擎：逐字符判定、虚拟键盘、实时指标、结果页
    └── app.js            路由、各页面渲染、导入解析、设置与交互
```

页面采用 hash 路由：`#/home`、`#/courses`、`#/stats`、`#/errors`、`#/settings`、`#/practice/<关卡 id>`。

## 如何新增一种界面语言

界面文案与页面逻辑是分离的，新增语言不需要改动任何页面代码：

1. 复制 `assets/lang/en.js` 为 `assets/lang/xx.js`（`xx` 为语言代码，如 `ja`、`ko`），把注册名与文案替换掉：

   ```js
   window.I18N.register("ja", {
     name: "日本語",
     dict: {
       "app.title": "指間 · タイピングスタジオ",
       // …其余与 zh.js / en.js 的 key 一一对应
     }
   });
   ```

2. 在 `index.html` 的语言包加载处新增一行（放在 `zh.js` 之后即可）：

   ```html
   <script src="assets/lang/xx.js"></script>
   ```

完成后，设置页的语言下拉会自动出现这个选项（由 `I18N.list()` 生成）。新语言缺失的 key 会自动回退到中文，因此可以分批翻译。

注意事项：

- 语言包使用同一套语义 key（如 `nav.home`、`settings.language`、`course.words.title`），可从 `zh.js` 完整复制后逐条替换；
- 课程标题、关卡标题与提示、成就名称与描述也都在语言包中（`course.<课程 id>.lNN.title`、`ach.<成就 id>.name` 等）；
- 支持 `{name}` 形式插值，带参数的文案请保留占位符；
- 练习内容（英文单词、句子）与其中文释义属于数据而非界面文案，不做翻译。

## 数据存储与限制

- 所有数据保存在浏览器 `localStorage`，键名为 `zhijian.typing.v1`，内容包括：设置、XP、关卡进度、导入内容、练习记录（最多保留最近 300 条）、每日统计、错词与按键错误、成就解锁时间。
- 数据仅存在于当前浏览器、当前站点下：
  - 更换浏览器、使用无痕窗口、更换设备或清除浏览器数据后，记录会丢失；
  - 通过 `file://` 打开与通过本地服务器 / GitHub Pages 打开，属于不同的存储域，数据不会互通。
- 建议在设置 → 数据中定期使用「导出数据」备份为 JSON；换环境后用「导入数据」恢复。
- 「清空数据」会重置全部记录与设置，操作前会有确认提示。
- 语音朗读依赖系统与浏览器自带的语音合成，音质与可用音色因操作系统、浏览器而异；离线时若没有本地英文音色，朗读可能不可用或退化为默认音色。应用本身不调用任何在线接口。
- 导入内容的解析上限为 400 个单词 / 200 个句子，单个导入文件不超过 2 MB。

## 技术说明

- 原生 HTML / CSS / JavaScript，经典 `<script>` 方式加载，无打包工具、无框架、无 CDN、无网络请求；
- 练习输入的按键监听不依赖外部库，虚拟键盘与热力图均由脚本绘制；
- 界面文案通过 `data-i18n` 系列属性与 `I18N.t()` 统一取值，新增文案时请同时更新 `zh.js` 与 `en.js`，避免回退到中文。
